## 1. 审计范围与结论

本审计只判断 G5-03 设计合同中已经授权的窄边界：DecisionPort 之后的同步
shadow observer 是否默认关闭、只读、无模型、无网络、无真实消费者副作用，并且
在失败、预算、取消、队列、非法结果、隐私拒绝和同步 stale fingerprint 情况下保持
deterministic primary 不变。

**结论：G5-03 在上述限定边界内通过退出。** 该结论不等价于 Laya provider、异步
迟到响应丢弃、真实 memory/KB 写入资格、权限判定、scheduler、terminal 或主动消息
已经实现；这些能力明确转入 G5-04 及后续独立施工单。

## 2. 代码锚点与不变量

| 位置 | 审计锚点 | 证明的边界 |
| --- | --- | --- |
| `crates/yunxi-core/src/decision.rs` | `DecisionPort`、request/result 校验、privacy gate、canonical fingerprint | request 先过版本、candidate、scope、payload 和隐私校验；失败时 fail-closed |
| `crates/yunxi-core/src/decision_shadow.rs` | `ShadowMode`/`Default` | 默认 `Disabled`；关闭时仍执行输入/primary 校验，但不调用 provider、不产生 observation |
| 同上 | `ShadowBudget`、`ShadowCallContext` | 有效 deadline 取 request/budget 最小值；调用前零预算/取消 fail-closed；进入同步 provider 后仅协作式读取 context，无强制中断 |
| 同上 | `ShadowQueue`、`ShadowPermit` | 原子 in-flight 容量与 RAII 释放；成功、错误、非法、超时路径均不泄漏 permit |
| 同上 | `observe_with_budget`、`observe_with_queue`、`validate_result` | deterministic primary 是唯一权威结果；shadow 只比较和记录，不改变 primary |
| 同上 | `ShadowObservation`、`observation_replay_bytes/digest` | 固定 envelope、最小脱敏字段、无原文，可稳定回放 |
| 同上 | `ShadowMatchKind` | exact/outcome/mismatch/abstain、invalid、timeout、cancelled、unavailable、privacy、queue、同步 stale 分类稳定 |
| 同上 | consumer probe tests | 仅验证 fake probe 读取 primary；不把 fake probe 伪装成真实消费者接入 |

观测不包含 raw message、profile、memory/KB 文本、terminal 原命令、路径、token、密码、
私钥、API key 或 prompt/cache 原文；非法 provider identity 被归一为 `unknown`。

## 5. 故障、隐私与主路径不变性

- disabled、provider 缺失、provider error、invalid result、timeout、cancelled、queue
  full 和 privacy rejection 均保留 deterministic primary。
- 请求未通过 DecisionPort privacy gate 时，provider 调用计数为 0；provider 自身返回
  `PrivacyRejected` 只会在已过 gate 的 request 上记录。
- 取消、零有效 deadline、零 queue slots、queue acquire 失败均在 provider 调用前 fail-closed。
- 已进入同步 provider 后没有线程强杀、异步 cancel token 或硬超时保证；`ShadowCallContext`
  只提供 provider 可主动检查的 deadline。不能把这段协作式语义写成硬取消。
- 同步 stale fingerprint 会被分类为 `StaleFingerprint`；异步网络响应的迟到丢弃未实现、
  未验证，不能由本审计代替。
- replay envelope/digest 采用固定字段顺序；consumer probe 只读 primary，shadow 不能
  增加写入、权限检查或调用其它系统边界。
